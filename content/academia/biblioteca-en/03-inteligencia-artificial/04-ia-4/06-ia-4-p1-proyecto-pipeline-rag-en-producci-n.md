## Project brief

Implement a RAG (Retrieval-Augmented Generation) system that answers questions over a set of your own documents. Use embeddings, a vector store and an LLM. The system must be available via API or web interface.

## Deliverables
- Code for the full pipeline on GitHub
- Minimum 20 indexed documents
- API or interface for asking questions
- Quality evaluation: 10 questions with expected answers
- README with architecture explained

## Rubric
- Relevant retrieval on >80% of test queries
- Grounded answers (no obvious hallucinations)
- System available for demo
- Architecture documented with a diagram

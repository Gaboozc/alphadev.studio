id: geo-2-p1 | type: project | difficulty: intermediate

## Project brief

Take an existing page on your site (or a client's) and rewrite it applying all GEO principles: clear definition, sourced data, list/step structure, schema markup and E-E-A-T. Document the changes and justify every decision.

## Deliverables
- URL of the original page
- Rewritten version with changes marked and justified
- Schema markup added (JSON-LD code)
- Analysis: what questions the page now answers that it didn't answer before

## Rubric
- Direct answer to a question in the first paragraph
- At least 2 statistical data points with cited sources
- Clear, descriptive H2/H3 structure
- Schema markup properly implemented

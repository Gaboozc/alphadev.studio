## Project brief

Build a complete design system in Figma for a web application. It must include design tokens, components from atoms up to organisms, and usage documentation for each component.

## Deliverables
- Shared Figma file with the design system
- Minimum 20 components organized under Atomic Design
- Color, typography and spacing tokens documented
- Documentation page with usage guide
- Demo of a complete screen built with the system

## Rubric
- Visual consistency across all components
- Professional naming and organization
- Components with variants and states
- Documentation thorough enough for another designer

# Unit 3 — Graded Exercises

Solutions in `../claves/u3-soluciones-ejercicios.md`.

## Level 1 [AUTO]

**1.1** Which button is best for confirming a subscription cancellation? a) "Yes" b) "OK" c) "Cancel subscription" d) "Continue"

**1.2** Which principle (clear, concise, useful, consistent, human) does each text break?
a) "Click this button in order to proceed with saving the changes you have made." b) One screen says "Cart" and another says "Bag." c) "Error 500." d) "The operation has been completed satisfactorily by the system."

**1.3** Which is correct for a button under a sentence-case style guide? a) "Create New Project" b) "Create new project" c) "CREATE NEW PROJECT" d) "create new project"

**1.4** A good error message answers (choose all that apply): a) what happened b) who coded the feature c) what the user can do d) the internal code as the main text

## Level 2 [HUMAN]

**2.1** Rewrite: (a) "Required field." (on a form with 12 fields); (b) "No data." (in the invoices section); (c) "Invalid password." (at sign-up); (d) "Do you want to continue? [Yes] [No]" (when leaving an editor with unsaved changes).

**2.2** Review 3 apps or websites you use. Find 3 examples of bad microcopy (screenshot or transcription), explain the problem and propose a better version.

## Level 3 [HUMAN]

**3.1** Write all the microcopy for an online store's checkout flow (cart → shipping details → payment → confirmation), including at least 2 error messages and 1 empty state (empty cart). Include a minimal style guide (section 4).

**3.2** Run a comprehension test with 3 people on your flow from 3.1 (or a real product's). Document where they hesitated and what you changed.

# Unit 3 — Quiz

Key in `../claves/u3-clave-cuestionario.md`. **Part A [AUTO]** · **Part B [HUMAN]**

1. The main goal of UX writing is to:
   a) Sell more on every screen. b) Rank in search engines. c) Entertain the user. d) Guide and reduce friction.
2. Using "Delete" on one screen and "Remove" on another for the same action breaks the principle of:
   a) Concision b) Clarity c) Human tone d) Consistency
3. A placeholder as the only label is a problem because:
   a) It isn't, if the placeholder text is clear. b) It disappears when you type and has low contrast. c) It takes up too much space inside the field. d) Design standards require it.
4. An error message should NOT:
   a) Say what happened. b) Suggest an action. c) Blame the user. d) Appear next to the field.
5. A useful empty state:
   a) Explains what will go there and how to get started. b) Is left blank so it doesn't distract the user. c) Says "No data" neutrally and briefly. d) Shows an error to flag that it's empty.
6. A product's voice:
   a) Changes on every screen. b) Is the same as tone. c) Is stable; the tone adapts. d) Doesn't matter if the text is clear.
7. "Click here" as link text is bad practice because:
   a) It's too long for a link on mobile. b) It doesn't say where it goes and hurts accessibility. c) It sounds too casual for a company website. d) It's a marketing phrase, not an interface phrase.
8. To write a technical error well, you first need to:
   a) Hide it so you don't scare the user. b) Make it funny to soften it. c) Understand what it means, with the engineering team. d) Make it red and bold so it's seen.
9. "If there's an account with that email, we've sent a link" is written that way for:
   a) Security: not revealing whether an email is registered. b) Laziness: it's generic template text. c) Style: it sounds friendlier than an error. d) A bug: the system doesn't know whether the account exists.
10. The simplest microcopy test is:
    a) Counting the words on each screen. b) Watching someone do a task without help. c) Asking your boss if they like the copy. d) Running a spell checker on the text.

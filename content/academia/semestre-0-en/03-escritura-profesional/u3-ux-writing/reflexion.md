# Unit 3 — Reflection (reviewed with a rubric)

## Prompt (300–500 words)
Think about the last time some text in an app or website frustrated you or made you give up on something.
1. Describe the situation and the text.
2. Which principle was failing? What did you need to know at that moment?
3. Propose a better version.
4. If you work (or will work) on products (software, design or marketing), what responsibility do you have for interface copy?

## Rubric (12 points)
| Criterion | 3 | 2 | 1 | 0 |
|---|---|---|---|---|
| Description | A specific situation and text | Generic | Vague | Missing |
| Analysis | Principle and user need correctly identified | Principle without the need | Superficial | Missing |
| Proposal | A clear improvement applying the principles | A partial improvement | Minor changes | Missing |
| Professional responsibility | A specific reflection based on their role | General | Vague | Missing |

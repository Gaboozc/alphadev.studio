# Unit 3 — Quiz

Key in `../claves/u3-clave-cuestionario.md`. **Part A [AUTO]** · **Part B [HUMAN]**

1. *Few-shot* means:
   a) Including several input-output examples in the prompt. b) Using a small model trained on little data. c) Using few tokens so the answer is short. d) Asking few questions per new conversation.

2. Why can asking for the reasoning before the conclusion improve the result?
   a) Because the model works more slowly and carefully. b) Because it reduces the tokens the model needs. c) Because it automatically turns on web search. d) Because the written steps shape the conclusion.

3. With a model that already reasons internally, asking for step by step is still useful mainly to:
   a) Lower the total cost of the request. b) Be able to review the assumptions and data used. c) Nothing: the model already reasons on its own. d) Make the answer arrive faster.

4. What's the main advantage of a prompt chain?
   a) It avoids having to write clear instructions. b) It creates checkpoints to review each step. c) It always uses fewer tokens than a single prompt. d) It eliminates hallucinations in the result.

5. Delimiters are for:
   a) Increasing the model's context window. b) Decorating the prompt so it reads better. c) Separating instructions from pasted material. d) Telling the model which language to answer in.

6. When asking for JSON, saying "if a piece of data is missing, use null":
   a) Breaks the JSON format and forces a retry. b) Reduces the risk of it making up values. c) Makes the model use a higher temperature. d) Is unnecessary: the model never leaves gaps.

7. When should you start a new conversation?
   a) Always after three or four messages in a row. b) Only when you switch models or tools. c) Never: more context always improves the answer. d) When it has drifted or ignores the initial instructions.

8. One risk of few-shot examples is that:
   a) The model copies their structure or phrasing too closely. b) The examples don't work if the text isn't in English. c) They always increase hallucinations in the output. d) The model ignores the examples and answers its own way.

9. In a prompt library, noting the date and tool it was tested with matters because:
   a) It takes up little space and keeps the library organized. b) It's for billing the client for each prompt used. c) Models change and their answers can vary. d) The law requires logging every prompt.

10. When asking AI for code, what should you especially check?
    a) That every single line has a comment. b) That it's written in English, like the documentation. c) That it's as short as possible, even if cryptic. d) That the functions and libraries exist and work.

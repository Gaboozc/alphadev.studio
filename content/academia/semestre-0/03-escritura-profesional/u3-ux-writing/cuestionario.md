# Unidad 3 — Cuestionario

Clave en `../claves/u3-clave-cuestionario.md`. **Parte A [AUTO]** · **Parte B [HUMANO]**

1. El objetivo principal del UX writing es:
   a) Vender más en cada pantalla. b) Posicionar en buscadores. c) Entretener al usuario. d) Guiar y reducir fricción.
2. Usar "Guardar" en una pantalla y "Salvar" en otra viola el principio:
   a) Concisión b) Claridad c) Tono humano d) Consistencia
3. Un placeholder como única etiqueta es problemático porque:
   a) No lo es, si el texto del placeholder es claro. b) Desaparece al escribir y tiene poco contraste. c) Ocupa demasiado espacio dentro del campo. d) Es obligatorio según las normas de diseño.
4. Un mensaje de error NO debería:
   a) Decir qué pasó. b) Proponer una acción. c) Culpar al usuario. d) Mostrarse junto al campo.
5. Un estado vacío útil:
   a) Explica qué irá ahí y ofrece cómo empezar. b) Se deja en blanco para no distraer al usuario. c) Dice "Sin datos" de forma neutral y breve. d) Muestra un error para avisar del vacío.
6. La voz de un producto:
   a) Cambia en cada pantalla. b) Es lo mismo que el tono. c) Es estable; el tono se adapta. d) No importa si el texto es claro.
7. "Haz clic aquí" como texto de enlace es mala práctica porque:
   a) Es demasiado largo para un enlace en móvil. b) No dice a dónde lleva y daña la accesibilidad. c) Suena demasiado informal para una web de empresa. d) Es una frase de marketing, no de interfaz.
8. Para escribir bien un error técnico, primero hay que:
   a) Ocultarlo para no asustar al usuario. b) Hacerlo gracioso para restarle peso. c) Saber qué significa con el equipo técnico. d) Ponerlo en rojo y en negrita para que se vea.
9. "Si existe una cuenta con ese correo, te enviamos un enlace" se escribe así por:
   a) Seguridad: no revelar si un correo está registrado. b) Pereza: es un texto genérico de plantilla. c) Estilo: suena más amable que un error. d) Error: el sistema no sabe si la cuenta existe.
10. La prueba más simple de microcopy es:
    a) Contar las palabras de cada pantalla. b) Observar a alguien hacer una tarea sin ayuda. c) Preguntar al jefe si le gusta el texto. d) Pasar un corrector ortográfico al texto.
